## 4. Gotchas (learned this session)
- Editing = **localized inpainting** (`refine.py:_edit_locality_mask`, blend `edited·(1-w)+snap·w`), NOT global
  SDEdit. Eval the snap localized or the result is misleading (global re-mold blobs the whole body).
- `HybridDataset` must emit IDENTICAL dict keys on bag+recipe paths (era/floors/region) or `default_collate`
  KeyErrors on the first MIXED batch. era/floors gating = per-item bounds-check (NL rows keep labels, DE/JP unknown).
- `--ckpt` ⇒ train.py prefixes the run dir with `continue-`. Per-1k checkpoint save ≈ 16 min on Lustre → save sparingly.
- Monitor the REAL loss line `(GPU: N, iters:` (not `lr_decay_iters`/`total_iters` echoes); use `loss_log.txt` or
  `PYTHONUNBUFFERED=1` (stdout block-buffers to a file otherwise).
- Layer-A: expanded input conv ⇒ skip optimizer restore (fresh optimizer); zero-init new channels for identity warm-start.
- Memory store (`.../memory/`) was empty at session start; now seeded — see `MEMORY.md`.
