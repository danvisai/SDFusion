How to read this

envelope is the footprint pushed up to the height — the input every arm starts from, and the thing a carve has to improve on.

heightmap (mode / median) is #127's 3.4M-parameter generator. The two differ only in how the per-column prediction is read out — that one line is the ticket's headline finding.

retrieval copies the roof of the nearest training footprint. Zero training. On the held-out set it loses on surplus and wins on looks.

a2 is the shipped 49M model, for reference. Slowest arm by far (~7 s).

⚠️ What this cannot tell you

A footprint you drew has no ground truth, so missing and extra — the numbers #127 is actually judged on — cannot be computed here. The only number shown is vs input: 1.000 means the arm returned the envelope unchanged.

The judgement this page supports is visual, which is the criterion #127 measured its own scorecard to be blind to. Look for planes meeting at a ridge versus a rounded mound.
