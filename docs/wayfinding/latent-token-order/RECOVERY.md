⚠️ **Two defects #88 found are still live in this clone**, and they are not confined to #87:

- `scene/surface_sampling.py:69` — `sample_uniform(mesh, n, rng=None)` accepts `rng` and never uses
  it; `trimesh.sample.sample_surface` draws from numpy's **global** generator.
- `models/shape_codec.py:165` — `DoraCodec` seeds one `self.rng` at construction that every
  `encode` advances, so a building's encode depends on every building encoded before it.

Together these mean **every latent produced on this box is a function of global interpreter state
and call order.** That reaches the shipped town demo: `town_generate_service.py` encodes per
building, which is the mechanism behind the run-to-run spread recorded on
[#93](https://github.com/danvisai/SDFusion/issues/93) (0.2268 at strength 0.7 on the L-plan).
Whoever re-lands #88's capture path should fix these first — they are a correctness bug here
regardless of what #87 decides.
