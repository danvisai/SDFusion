# Triage labels

The skills use five canonical roles. This table maps each role to the GitHub label and gives its plain-language meaning.

| Skill role | GitHub label | Human meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer review |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous work |
| `ready-for-human` | `ready-for-human` | Ready, but requires human involvement |
| `wontfix` | `wontfix` | Intentionally not being pursued |

When a skill mentions a role, use the corresponding GitHub label in this table.
